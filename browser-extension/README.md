# Galaxy Bunny Tracker Bridge

1. Lance le serveur Galaxy Bunny.
2. Ouvre `edge://extensions` dans Edge.
3. Active le mode développeur.
4. Choisis **Charger l’extension décompressée** et sélectionne ce dossier.
5. Ouvre ton overlay Tracker.gg connecté.

L’extension lit uniquement le texte visible de la page et l’envoie à `localhost:8769`. Elle ne lit ni mot de passe, ni cookie, ni clé API.
